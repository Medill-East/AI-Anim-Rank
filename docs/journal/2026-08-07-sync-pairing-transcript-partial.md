## 用户问题

用户在两台电脑上尝试使用配对二维码同步个人标记，发现无法同步，询问是否只能通过本地备份。

## 关键检查

- `SyncSettings` 只读取/保存 `SyncVaultStore`，二维码序列化的是 `phrase + salt`。
- `SyncClient` 虽然存在并有协议测试，但在应用组件中没有被引用。
- `VITE_SYNC_BASE_URL` 只传给 `AppStatus`，原逻辑仅显示“端点已配置”，没有真正执行网络同步。
- `worker/wrangler.toml` 的 D1 ID 仍是占位值；Cloudflare 查询显示同步 Worker 不存在。

## 已执行的实现方向

- 新增 `HttpSyncTransport`，实现同步 Worker 的 GET/PUT 与 ETag 版本处理。
- 保险库变化时由排行榜工作区创建同步客户端；进度加载完成后自动同步；本地保存后进入同步队列。
- 私密同步界面增加同步状态和“立即同步”；无端点时明确提示二维码只能迁移凭证。
- 本地检查：TypeScript、同步测试和 DOM 测试通过。
